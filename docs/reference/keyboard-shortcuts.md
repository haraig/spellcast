# Keyboard shortcuts

## Anywhere

| Keys | Action |
|---|---|
| CapsLock + 1 to 9 | Run the action on that digit on the selected text |
| Shift + CapsLock | Toggle caps lock (CapsLock alone does not) |

## In the result window

| Keys | Action |
|---|---|
| Ctrl + Enter | Replace the selection with the answer |
| Ctrl + C | Copy the selected part of the answer, or the whole raw answer if nothing is selected |
| Ctrl + D | Show changes on or off |
| Esc | Close the window (cancels a running request) |

## In the API key and About windows

| Keys | Action |
|---|---|
| Esc | Close the window |
