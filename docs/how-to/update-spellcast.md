# How to update Spellcast

Updating means replacing `spellcast.exe` with the new one. Your config, your API key and the usage totals are stored outside the exe, so they stay.

1. See which version you have: tray menu, **Help** > **About Spellcast**. What changed in each version is in the [release notes](https://github.com/haraig/spellcast/releases) and in [CHANGELOG.md](../../CHANGELOG.md).
2. Download the new `spellcast.exe` from the [latest release](https://github.com/haraig/spellcast/releases/latest). To check it, see [Install Spellcast](install-spellcast.md#check-the-download-optional).
3. Quit Spellcast: tray menu, **Quit**.
4. Replace the old `spellcast.exe` with the new one, in the same folder and with the same name. Then **Start with Windows** keeps working.
5. Start `spellcast.exe`. SmartScreen may warn again, because it is a new file: choose **More info** > **Run anyway**.
